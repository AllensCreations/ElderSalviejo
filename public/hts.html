What if I don't have a domain?

Good news: You do NOT need to purchase or own a domain! The entire system is engineered to run 100% free with zero domain fees using one of two free pathways:

Approach Requires Domain? Cost Trigger Speed How It Works
Option A: Native Google Apps Script NO $0.00 (Free) Every 60 sec Elder Salviejo emails your free @gmail.com receiver. Script checks inbox every minute.
Option B: Cloudflare Workers (*.workers.dev) NO $0.00 (Free) Every 60 sec Uses Cloudflare's free your-account.workers.dev subdomain to run an automated cron trigger.
Option C: Cloudflare Email Routing YES (Any domain) Free via CF 0.0s (Sub-second) Elder Salviejo emails journal@yourdomain.com. Cloudflare intercepts and triggers instantly.
Recommended Recommendation: If you don't have a domain, use Option A (Google Apps Script with 1-Minute Trigger). It runs directly inside your free Gmail account with zero extra configuration or external tools!

How Option A Operates Without a Domain:

  1. You create a free Gmail account (e.g. eldersalviejo.archive@gmail.com).
  2. You paste our google-apps-script/Code.gs code into script.google.com.
  3. You run createNearInstantTrigger once.
  4. Google will automatically inspect the inbox every 60 seconds. Whenever an email arrives with passcode 159266 or 073000, it is ingested, saved to Turso/GitHub, and confirmed!

Google Apps Script: Complete Setup in 5 Steps

This script runs inside your dedicated receiver Gmail account to monitor emails and transmit them to your website.

1 Open Google Apps Script

Log into your dummy Gmail receiver account, go to script.google.com, and click + New project. Name it Elder Salviejo Diary Processor.

2 Copy Code.gs & Manifest

  • Replace the contents of Code.gs with the code in google-apps-script/Code.gs from this repository.
  • Click Project Settings (gear icon on the left) > Check "Show 'appsscript.json' manifest file in editor".
  • Open appsscript.json and replace it with google-apps-script/appsscript.json.

3 Configure Script Properties (Private Secrets)

In Project Settings, scroll to Script Properties and add:

PropertyExample ValueDescription
VERCEL_INGEST_URL https://eldersalviejo.vercel.app/api/ingest Your live production ingest endpoint
INGEST_SECRET your-super-secret-token Secret authorization token (must match server .env)
SECRET_DIARY_CODE 159266 Passcode filter for weekly journal reflections
SECRET_GALLERY_CODE 073000 Passcode filter for direct photo gallery uploads
SITE_URL https://eldersalviejo.vercel.app Public website address

4 Activate the Near-Instant 1-Minute Trigger

In the Apps Script toolbar function dropdown, select:

createNearInstantTrigger

Click Run and authorize permissions when prompted. The execution log will report:

SUCCESS: Near-Instant 1-Minute Trigger active!
The script will check your inbox every 60 seconds automatically.

5 Deploy as a Web App (For Instant Webhook Ping)

  1. Click Deploy (blue button top right) > New deployment.
  2. Click gear icon > Select Web app.
  3. Execute as: Me | Who has access: Anyone.
  4. Click Deploy and copy the Web App URL.

Cloudflare Workers: Setup With Free *.workers.dev

Cloudflare Workers gives every free account an unlimited *.workers.dev address. You can deploy our included worker script to serve as an ultra-reliable external cron or webhook dispatcher.

Deploying with Wrangler (Free Subdomain):

  1. Open your local terminal in the project directory: 
    cd cloudflare
  2. Log into Cloudflare (opens a browser window): 
    npx wrangler login
  3. Store your private Google Apps Script Web App URL and Ingest Secret securely: 
    npx wrangler secret put APPS_SCRIPT_URL
# Paste your Apps Script Web App URL: https://script.google.com/macros/s/.../exec

npx wrangler secret put INGEST_SECRET
# Paste your secret token
  4. Deploy to your free *.workers.dev subdomain: 
    npx wrangler deploy
Instant Ping Endpoint: Once deployed, visiting https://elder-salviejo-email-trigger.your-name.workers.dev/trigger will instantly trigger your Google Apps Script without delay!

If You Acquire a Custom Domain Later:

When you add a domain to Cloudflare, you can enable Cloudflare Email Routing in 2 minutes:

  1. Go to Email Routing > Routes > Create rule.
  2. Custom Address: journal@yourdomain.com
  3. Action: Send to Worker > Select elder-salviejo-email-trigger.

Incoming emails to that address will invoke the worker in 0.0 seconds.
